# 如何启动项目

> 本文档记录 ssp-comment-center 评论中心从环境准备到服务启动的完整步骤，以及实际踩坑与修复记录。  
> 适合豆包、ChatGPT、Cursor、Claude 等 LLM 快速阅读与检索。

---

## 一、环境依赖

| 依赖 | 版本要求 | 用途 |
|------|---------|------|
| Java | 21+（当前环境为 Java 25） | Spring Boot 3.0.7 运行 |
| Maven | 3.9+ | 编译打包 |
| Node.js | 18+ | 前端 React 工程构建 |
| MySQL | 8.0 | 2 个分库 + 审核表 |
| Redis | 7.x | 缓存、点赞状态、热评 ZSet |
| Docker | 任意 | 一键启动 MySQL |

当前机器环境（macOS ARM64）：
- Java 25.0.1（OpenJDK）
- Maven 3.9.11（Homebrew：`/opt/homebrew/bin/mvn`）
- Node.js 20.x（Homebrew：`/opt/homebrew/bin/node`）
- Docker Desktop 28.5.2
- Redis 7（Homebrew：`/opt/homebrew/bin/redis-server`）

## 二、环境准备

### Step 1：启动 MySQL（Docker）

```bash
# 启动 Docker Desktop（macOS）
open -a Docker

# 启动 MySQL 容器
docker run -d --name mysql-comment \
  -e MYSQL_ROOT_PASSWORD=root \
  -p 3306:3306 mysql:8.0

# 等待 5~10 秒让 MySQL 完全启动
sleep 5
```

> **踩坑记录**：本地 `mysql` 客户端版本 9.6.0 已不支持 `mysql_native_password` 插件，直接连容器会报 `ERROR 2059`。  
> **解决**：用容器内部的 mysql 客户端执行 DDL，绕过本地客户端版本不兼容问题。

```bash
# 执行建库建表脚本（推荐方式）
docker exec -i mysql-comment mysql -u root -proot < docs/05-database/ddl-sharding.sql

# 验证数据库和表是否创建成功
docker exec mysql-comment mysql -u root -proot -e "SHOW DATABASES LIKE 'ssp_comment_%';"
docker exec mysql-comment mysql -u root -proot -e "USE ssp_comment_0; SHOW TABLES;"
docker exec mysql-comment mysql -u root -proot -e "USE ssp_comment_1; SHOW TABLES;"
```

预期输出：
- 2 个数据库：`ssp_comment_0`、`ssp_comment_1`
- 每个库包含：`component_comment_0~3`、`component_comment_reply_0~3`、`component_comment_like_0~3`、`component_user_comment_index_0~3`、`component_notification_0~3`
- `ssp_comment_0` 额外包含单表：`component_comment_audit`

### Step 2：启动 Redis

```bash
# 方式 A：Homebrew 已安装的 Redis（推荐）
redis-server --daemonize yes --port 6379

# 验证
redis-cli ping
# 预期输出：PONG
```

> **踩坑记录**：Docker 拉取 Redis 镜像时网络不稳定，多次 `docker run redis:7` 均失败。  
> **解决**：改用本地 Homebrew 已安装的 Redis 二进制启动。

### Step 3：确认 Maven 可用

```bash
# 如果 mvn 命令找不到，Homebrew 安装的 Maven 路径如下
export PATH="/opt/homebrew/bin:$PATH"
mvn -version
```

## 三、编译打包

### 3.1 进入项目根目录

```bash
cd ~/ssp-comment-center
export PATH="/opt/homebrew/bin:$PATH"
```

### 3.2 编译

```bash
mvn clean compile -DskipTests
```

> **踩坑记录 1**：`maven-compiler-plugin 3.11.0` + `Lombok 1.18.30` 在 Java 25 下编译报 `ExceptionInInitializerError: com.sun.tools.javac.code.TypeTag :: UNKNOWN`。  
> **修复**：`pom.xml` 中升级 `maven-compiler-plugin` 到 `3.13.0`，`Lombok` 到 `1.18.38`，`source/target` 改为 `21`。

> **踩坑记录 2**：`mvn spring-boot:run -pl ssp-comment-center-start` 直接运行会报依赖找不到，因为子模块未 install 到本地仓库。  
> **解决**：先执行 `mvn clean install -DskipTests` 全量打包。

### 3.3 全量打包（install 到本地仓库）

```bash
mvn clean install -DskipTests
```

预期输出：
```
[INFO] ssp-comment-center ................................. SUCCESS
[INFO] ssp-comment-center-domain .......................... SUCCESS
[INFO] ssp-comment-center-infrastructure .................. SUCCESS
[INFO] ssp-comment-center-application ..................... SUCCESS
[INFO] ssp-comment-center-start ........................... SUCCESS
[INFO] BUILD SUCCESS
```

## 四、启动 Spring Boot 服务

### 方式 A：直接运行 jar（推荐，稳定）

```bash
cd ~/ssp-comment-center
java -jar ssp-comment-center-start/target/ssp-comment-center-start-1.0.0-SNAPSHOT.jar
```

服务启动后监听 `http://localhost:8080`。

### 方式 B：后台运行（不占用当前终端）

```bash
cd ~/ssp-comment-center
java -jar ssp-comment-center-start/target/ssp-comment-center-start-1.0.0-SNAPSHOT.jar > /tmp/springboot.log 2>&1 &
echo $! > /tmp/springboot.pid
```

查看启动日志：
```bash
tail -f /tmp/springboot.log
```

验证启动成功：
```bash
lsof -i :8080 | grep LISTEN
# 预期输出：java ... TCP *:http-alt (LISTEN)
```

### 方式 C：Maven 插件启动（开发调试）

```bash
mvn spring-boot:run -pl ssp-comment-center-start -DskipTests
```

> 注意：此方式要求子模块已 `mvn install`，否则报 `Could not resolve dependencies`。

## 五、启动前端服务（React + TypeScript + Ant Design）

前端工程位于 `web/` 目录，独立部署，通过 Vite dev server 代理 `/api` 请求到后端 `8080`。

### 前置条件

- 后端 Spring Boot 已启动在 `http://localhost:8080`
- Node.js 18+ 和 npm 已安装

### 安装依赖

```bash
cd ~/ssp-comment-center/web
npm install
```

### 开发模式启动

```bash
cd ~/ssp-comment-center/web
npm run dev
```

预期输出：
```
  VITE v5.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: http://192.168.x.x:3000/
  ➜  press h + enter to show help
```

前端服务启动后自动打开浏览器，访问 `http://localhost:3000` 即可进入评论中心演示页。

> **注意**：Vite 配置中已将 `/api` 路径代理到 `http://localhost:8080`，前端无需处理跨域。确保后端 8080 端口已启动，否则前端页面加载评论时会报错。

### 前端工程结构速览

```
web/
├── src/
│   ├── api/              # Axios 封装 + 业务接口（comment / like）
│   ├── components/       # 6 个业务组件（CommentList、CommentItem、ReplyTree、LikeButton、HotCommentList、UserSwitcher）
│   ├── pages/            # DemoPage.tsx（演示主页面）
│   ├── hooks/            # useUser.ts（全局用户上下文）
│   ├── types/            # TypeScript 类型定义（与后端接口契约对齐）
│   ├── utils/            # 常量与环境变量
│   ├── App.tsx           # UserContext + ConfigProvider（Ant Design 中文）
│   └── main.tsx          # React 18 createRoot 入口
├── vite.config.ts        # /api proxy → localhost:8080
└── package.json          # React 18 + TS + Ant Design 5.x + Axios
```

### 生产构建

```bash
cd ~/ssp-comment-center/web
npm run build
```

构建产物输出到 `web/dist/` 目录，可通过 Nginx 或任意静态服务器托管。

## 七、停止服务

```bash
# 停止后端
kill -9 $(lsof -i :8080 | grep LISTEN | awk '{print $2}')
# 或
kill -9 $(cat /tmp/springboot.pid)

# 停止前端（Ctrl + C 即可，或在另一个终端执行）
kill -9 $(lsof -i :3000 | grep LISTEN | awk '{print $2}')

# 停止 MySQL
docker stop mysql-comment

# 停止 Redis
redis-cli shutdown
```

## 七、常见问题排查

### Q1：`mvn` 命令找不到

```bash
# Homebrew 安装的 Maven 路径
export PATH="/opt/homebrew/bin:$PATH"
```

### Q2：编译报错 `ExceptionInInitializerError: com.sun.tools.javac.code.TypeTag :: UNKNOWN`

**原因**：Lombok 版本与 Java 25 不兼容。  
**解决**：`pom.xml` 中修改以下三项：

```xml
<properties>
    <lombok.version>1.18.38</lombok.version>
</properties>

<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-compiler-plugin</artifactId>
            <version>3.13.0</version>
            <configuration>
                <source>21</source>
                <target>21</target>
                <!-- annotationProcessorPaths 保持不变 -->
            </configuration>
        </plugin>
    </plugins>
</build>
```

### Q3：`mvn spring-boot:run` 报 `Could not resolve dependencies`

**原因**：子模块 jar 未 install 到本地 Maven 仓库。  
**解决**：先执行 `mvn clean install -DskipTests`。

### Q4：端口 8080 被占用

```bash
# 查找占用进程
lsof -i :8080

# 停止进程
kill -9 <PID>
```

### Q5：MySQL 连接失败 `Can't connect through socket`

**原因**：Docker MySQL 只暴露 TCP 端口，本地 mysql 客户端默认走 Unix socket。  
**解决**：用 `docker exec -i mysql-comment mysql -u root -proot` 执行 SQL，或加 `-h 127.0.0.1` 强制 TCP。

### Q6：MySQL 认证插件错误 `mysql_native_password cannot be loaded`

**原因**：本地 mysql 客户端 9.x 已移除 `mysql_native_password` 插件。  
**解决**：用容器内部客户端执行 DDL，不经过本地 mysql 命令。

### Q7：Redis 连接失败

```bash
# 检查 Redis 是否运行
redis-cli ping

# 如果未运行，启动
redis-server --daemonize yes --port 6379
```

## 八、一键启动脚本

项目根目录已提供 `start-all.sh`，关机重启后只需执行该脚本即可一键启动所有依赖服务：

```bash
cd ~/ssp-comment-center
chmod +x start-all.sh
./start-all.sh
```

脚本内容：

```bash
#!/bin/bash
set -e

echo "[1/3] 启动 Docker Desktop..."
open -a Docker
sleep 15  # 等待 Docker daemon 就绪

echo "[2/3] 启动 MySQL..."
docker start mysql-comment
sleep 3

echo "[3/3] 启动 Redis..."
redis-server --daemonize yes --port 6379

echo ""
echo "✅ 依赖服务已就绪"
echo "   MySQL:  localhost:3306"
echo "   Redis:  localhost:6379"
echo ""
echo "现在可以在 IDEA 中启动 CommentCenterApplication 了"
```

> **注意**：此脚本只启动 MySQL + Redis 依赖服务，**不启动 Spring Boot**。Spring Boot 请在 IDEA 中点击 `CommentCenterApplication` 的绿色 ▶️ 启动，方便开发调试和热部署。

## 十、配置说明

### application.yml 关键配置

- **MySQL**：`localhost:3306`，用户名/密码 `root/root`，2 个数据源 `ds_0` / `ds_1`
- **Redis**：`localhost:6379`，无密码，database 0
- **ShardingSphere**：2 库 × 4 表 = 8 张物理表/表类型
- **MyBatis**：`sql-show: true` 开启 SQL 日志

如需修改数据库密码或 Redis 地址，编辑：
`ssp-comment-center-start/src/main/resources/application.yml`
