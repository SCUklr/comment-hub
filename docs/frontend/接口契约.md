# 接口契约

> 本文档汇总 ssp-comment-center 所有 REST API，作为前端展示页与后端交互的唯一契约来源。所有接口均基于 `ssp-comment-center-start` 模块现有 Controller 整理。

---

## 一、通用约定

### 1.1 基础信息

- **Base URL**：`http://localhost:8080`
- **统一响应包装**：
  ```json
  {
    "code": 200,
    "message": "success",
    "data": { ... }
  }
  ```
- **认证方式**：Header 携带 `X-User-Id` 模拟登录用户；未携带时，`UserContext.getCurrentUserId()` 可能为 `null`。
- **内容类型**：POST 请求 `Content-Type: application/json`。
- **分页默认值**：`page=1`，`pageSize=20`。

### 1.2 状态码

| code | 含义 | 触发场景 |
|------|------|---------|
| 200 | 成功 | 业务处理成功 |
| 400 | 请求参数错误 | `@Valid` 校验失败、缺少必填字段 |
| 401 | 未登录 | 需要登录的接口未携带 `X-User-Id` |
| 403 | 无权限 | 操作他人评论/回复、非管理员置顶 |
| 404 | 资源不存在 | 评论/回复 ID 不存在或已删除 |
| 409 | 业务冲突 | 重复点赞、重复取消点赞 |
| 500 | 服务器内部错误 | 数据库异常、Redis 异常、未知异常 |

> 注：当前后端 `Result.fail(String message)` 默认返回 code=500，未严格按上述状态码细分；建议前端以 `code !== 200` 统一视为失败，并展示 `message`。

## 二、接口清单

### 2.1 评论相关接口

#### 2.1.1 创建评论 / 回复

- **Method**：`POST`
- **Path**：`/api/comment/create`
- **登录要求**：✅ 需要
- **请求 DTO**：`CommentCreateReqVO`

```json
{
  "type": 1,
  "commentObjectId": 10001,
  "commentType": 1,
  "commentId": null,
  "parentId": null,
  "beRepliedUserId": null,
  "content": "这是一条评论",
  "images": "[]"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | int | ✅ | 1=创建一级评论，2=创建回复 |
| `commentObjectId` | long | 条件 | `type=1` 时必填，被评论对象 ID |
| `commentType` | int | 条件 | `type=1` 时必填，业务类型 |
| `commentId` | long | 条件 | `type=2` 时必填，所属一级评论 ID |
| `parentId` | long | ❌ | `type=2` 且楼中楼时填写父回复 ID，默认 0 |
| `beRepliedUserId` | int | ❌ | 被回复用户 ID |
| `content` | string | ✅ | 内容，非空 |
| `images` | string | ❌ | 图片 URL JSON 字符串，默认 `"[]"` |

- **响应 DTO**：`CommentCreateRespVO`

```json
{
  "type": 1,
  "id": 720209260377591808,
  "commentObjectId": 10001,
  "commentType": 1,
  "commentId": null,
  "parentId": null,
  "replyType": null,
  "replyUserId": 10001,
  "beRepliedUserId": null,
  "content": "这是一条评论",
  "images": "[]",
  "createTime": "2026-06-11T17:34:28",
  "updateTime": "2026-06-11T17:34:28"
}
```

### 2.4 通知相关接口

#### 2.4.1 我的通知列表

- **Method**：`GET`
- **Path**：`/api/notification/list`
- **登录要求**：✅ 需要
- **请求参数**：`NotificationListReqVO`（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | ❌ | 1 | 页码 |
| `pageSize` | int | ❌ | 20 | 每页条数 |

- **响应 DTO**：`Result<PageResult<NotificationListRespVO>>`

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 10,
    "page": 1,
    "pageSize": 20,
    "list": [
      {
        "id": 720209260377591900,
        "type": 1,
        "subjectId": 720209260377591809,
        "subjectType": 2,
        "actorId": 10002,
        "commentObjectId": 10001,
        "commentType": 1,
        "content": "回复内容摘要",
        "isRead": 0,
        "createTime": "2026-06-12T17:34:28"
      }
    ]
  }
}
```

`NotificationListRespVO` 字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | long | 通知 ID |
| `type` | int | 1=回复通知，2=点赞通知 |
| `subjectId` | long | 触发对象 ID（评论/回复 ID） |
| `subjectType` | int | 1=评论，2=回复 |
| `actorId` | int | 触发者用户 ID |
| `commentObjectId` | long | 评论对象 ID |
| `commentType` | int | 业务类型 |
| `content` | string | 内容摘要 |
| `isRead` | int | 0=未读，1=已读 |
| `createTime` | datetime | 通知创建时间 |

---

#### 2.4.2 标记单条已读

- **Method**：`POST`
- **Path**：`/api/notification/read`
- **登录要求**：✅ 需要
- **请求 DTO**：`NotificationReadReqVO`

```json
{
  "id": 720209260377591900
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | long | ✅ | 通知 ID |

- **响应 DTO**：`Result<Boolean>`

```json
{
  "code": 200,
  "message": "success",
  "data": true
}
```

> `data` 为 `true` 表示成功标记，为 `false` 表示通知不存在或已读。

---

#### 2.4.3 标记全部已读

- **Method**：`POST`
- **Path**：`/api/notification/read/all`
- **登录要求**：✅ 需要
- **请求 DTO**：无

- **响应 DTO**：`Result<Boolean>`

```json
{
  "code": 200,
  "message": "success",
  "data": true
}
```

> 将当前登录用户所有未读通知标记为已读。

### 2.5 系统/审核接口

- **Method**：`POST`
- **Path**：`/api/comment/audit/callback`
- **登录要求**：❌ 不需要（供内部审核系统调用）
- **请求 DTO**：`CommentAuditCallbackReqVO`

```json
  "targetId": 720209260377591808,
  "targetType": 1,
  "auditStatus": 1,
  "auditReason": "审核通过",
  "auditOperator": 999
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `targetId` | long | ✅ | 目标 ID |
| `targetType` | int | ✅ | 1=评论，2=回复 |
| `auditStatus` | int | ✅ | 0=待审核，1=通过，2=拒绝 |
| `auditReason` | string | ❌ | 审核原因 |
| `auditOperator` | long | ❌ | 审核操作人 ID |

- **响应 DTO**：`Result<Void>`

> 前端展示页**不直接调用**此接口，仅作为后端/脚本能力存在。

## 三、前端调用时序示例

### 3.1 进入评论区

```
GET /api/comment/list?commentObjectId=10001&commentType=1&page=1&pageSize=20&topReplyLimit=3
```

### 3.2 发布评论

```
POST /api/comment/create
Header: X-User-Id: 10001
Body: { type:1, commentObjectId:10001, commentType:1, content:"..." }
```

成功后重新调用列表接口第一页。

### 3.3 发布回复

```
POST /api/comment/create
Header: X-User-Id: 10002
Body: { type:2, commentId:xxx, parentId:0, content:"..." }
```

### 3.4 点赞

```
POST /api/comment/like
Header: X-User-Id: 10003
Body: { targetId:xxx, targetType:1 }
```

成功后局部更新该条评论的 `liked` 和 `likeCount`。

### 3.5 展开更多回复

```
GET /api/reply/list?commentId=xxx&parentId=0&page=1&pageSize=20
```

### 3.6 切换热评 Tab

```
GET /api/comment/hot?commentObjectId=10001&commentType=1&page=1&pageSize=20
```
